# Sistema Financeiro

## Como rodar

> [!IMPORTANT]
> Antes de qualquer coisa, crie o arquivo ./app/config/.env a partir de uma cópia do .env-example encontrado no mesmo diretório.

```bash
docker compose up
```

Acessar sistema:
http://localhost:8080

> [!NOTE]
> Rodar testes
> ```bash
> cd app
> php tools/phpunit.phar
> ```
